# Robot Knights

Our team are very delighted to participate a second time in the World robot olympiad 2025, we are very excited to improve the robot we've been working on since last year "Knight", aiming to win the competition this time, have fun and learn more about programming and robots.

# Expectation:

Our team expects to pass the regional rounds and qualify for the national round for the second time, hoping to improve and surpass our previous scores. We also look forward to discovering other teams' strategies and robots, so we can learn and implement enhancements.

# "Knight":

This is the name of our robot. Its operation is based on circular movement across the mat during the open round, in which we aim to complete three laps and park in the shortest possible time. We attempt this using a motor that drives a directional module, which rotates a specific number of degrees and then advances until the gyroscope sensor calculates the degrees needed to determine that the robot has completed its three laps.

# Ev3:

We use a LEGO EV3 “brain,” which we could describe as a small computer programmed to interpret data sent from sensors and motors, and also to send signals back to them to perform various actions.

Regarding sensors, we use three: a gyroscope, which allows us to finish the rounds at the same spot where the robot started; an ultrasonic sensor, which detects how far away an obstacle is from the robot; and a set of color sensors that interpret the color of the obstacles based on the light reflected from them, so the robot can dodge in the correct direction.
